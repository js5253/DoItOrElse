# Do it... or else!
Do It or Else is an iOS App, made for my iOS Dev class, that tries to make the user achieve their to-dos with a bit of an... *alternative* incentive: if the user doesn't achieve their tasks, the app automatically donates a certain amount to a cause of their (anti-)choosing. For example, if they miss one task, e.g. doing their chores, it takes $20 * days missed from them and donates it to one of multiple causes: Republican Party, Democratic Party, the Mob Museum, the Chicago Food Bank, or Guitars Over Guns. This way things are done nonpartisanly and the user can choose whatever incentivizes them.

This app is programmed somewhat in SwiftUI and somewhat is Storyboards, and uses several APIs like EventKit and WebKit.
